# Web Programming Lab - Athlete Profile Page

An HTML/CSS practice page about HYROX athlete Amir Yehia.

## What it demonstrates
- Headings, paragraphs and external links
- Two local images with alternative text
- Form inputs and a styled content section
- CSS separated into an external stylesheet

## Files
- `index.html` - main page
- `style.css` - styling
- Two screenshot image files used in the page

## Open locally
Download or clone the repository, then open `index.html` in a browser. Keep `style.css` and the two image files in the same directory as `index.html`.

This is a student practice website. Profile statistics shown in the HTML are example content from the assignment and may change over time.
